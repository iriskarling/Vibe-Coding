# AI 产品经理个人博客模板

这是一个面向 **AI 产品经理简历展示** 的静态个人博客模板，适合作为：

- 求职/面试作品页
- 个人介绍主页
- 项目经历与方法论沉淀页

## 页面结构

- Hero（个人定位 + 核心成果）
- 代表项目（业务价值导向）
- 职业经历（时间线）
- 核心能力（标签化展示）
- 产品思考（博客摘要）
- 联系方式

## 本地预览

```bash
python3 -m http.server 8000
```

打开：`http://127.0.0.1:8000/index.html`

## 快速替换建议

1. 在 `index.html` 中替换姓名、邮箱、GitHub、微信。
2. 把项目数据替换为你的真实项目（建议每个项目保留 2~3 个量化指标）。
3. 把“产品思考”替换为你自己的文章标题或飞书/公众号链接。
4. 在 `styles.css` 中调整主色、字体和留白，形成个人品牌风格。
